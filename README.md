# Mirror Life OS

Mirror is a private personal operating system connecting vision, daily tasks, projects, prayer, sport, freedom trackers, skills, achievements, and a live future-performance score.

It opens directly with no account. All personal data stays in local storage on the device, so the APK does not require database secrets or an internet connection.

## Connected model

- Completing a task updates Today, its linked project, skill XP, performance, and the Future Card.
- Prayer, sport, and freedom trackers contribute to the Home performance score.
- Achievements unlock automatically from real progress across the system.
- Vision and projects shape the 90-day Future Card projection.

## APK releases

Push a version tag beginning with `v` to trigger the GitHub Actions Android build. The signed `mirror-life-os.apk` is attached to the matching GitHub release.
